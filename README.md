# Student Grade Calculator

## Project Description

The Student Grade Calculator is a simple Python project
that calculates student grades based on marks entered
by the user.

It uses conditional statements to assign grades according
to predefined grading conditions.

## Objectives

- Calculate total marks.
- Calculate average percentage.
- Assign grades based on marks.
- Practice Python conditional statements.
- Handle invalid user inputs.

## Technologies Used

- Python
- Google Colab

## Features

- Accepts student name and subject marks.
- Validates marks between 0 and 100.
- Calculates total marks.
- Calculates average percentage.
- Assigns grades using if, elif, and else.
- Displays the final result.

## Grading System

| Average Percentage | Grade |
|--------------------|-------|
| 90 - 100           | A     |
| 80 - 89.99         | B     |
| 70 - 79.99         | C     |
| 60 - 69.99         | D     |
| Below 60           | F     |

These are sample grading rules.

## How to Run

1. Install Python 3.
2. Download the Python source file.
3. Open the file in a Python editor.
4. Run the program.
5. Enter the student name and marks.
